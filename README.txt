EXPANDING POSTERS — portfolio for GitHub Pages

Upload the following to the ROOT of your existing GitHub repository:
  index.html
  styles.css
  script.js
  images/  (all 17 .webp files)

GitHub Pages should already be configured for the main branch / root.
No server, frameworks or build step are necessary.

Desktop: move the mouse over a poster to expand it; click to watch.
Mobile/touch: tap a poster to expand, then tap again (or use the view button) to watch.
Every project has an Open in Google Drive fallback in the viewer.
If JavaScript is off, poster and project links open the Drive videos directly.
