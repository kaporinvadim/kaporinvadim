# Vadim — Video Editor Portfolio

Static portfolio site. Video files stay on Google Drive; the site only hosts thumbnails and the interface.

## Free deploy with GitHub Pages
1. Create a public repository named `kaporinvadim.github.io`.
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings → Pages → Build and deployment → Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. The site will be available at `https://kaporinvadim.github.io/` after GitHub publishes it.

## Updating projects
Edit project cards in `index.html`. Google Drive player URLs use the file ID in `/file/d/FILE_ID/preview`.
